Karim Abo Kamel - Portfolio (final redesign)

How to run:
1. Unzip this folder anywhere.
2. Open a terminal inside the folder.
3. Run: npm install
4. Run: npm run dev
5. Open http://localhost:3000

Or to replace your current project: empty your old folder (keep the .git
folder if you have one) and drop these files in, then npm install.

Notes:
- Contact form: it uses FormSubmit. The FIRST time someone sends a message,
  FormSubmit emails karimabokamel74@gmail.com an activation link - click it
  once and the form is live.
- Projects, skills and text live in src/data/registry.ts and src/data/.
